# This is the initial commit for the Log order Book creatation

The aim of this project is to simulate the market using the help of log order books and using strategies from multiple research papers and model stocks / options in real world.

The psuedo work plan is a follows:
1. Creation of the Engine :
The first step is creating the matching engine. This will be an essential asset of the project. This allows us to match and record orders which would be placed. 
The main aim of this step is to create a fast and efficient system which could handle large amount of data.
The integeration of this with other things would be handles later

2. Study of LOB and how Markets may be mapped
In this phase we can study how different models have been created and use them to model different stocks.
I would like to start with basics and work our way up to more complex models to emulate.

3. Creation of a master model able to simulate any market.
With in depth reseach on simulations of markets, we would then go on to create a model capable of simulating Indian stocks and options. This is very vague right now and will be the accumulation of the research.
